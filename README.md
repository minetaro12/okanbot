## okanbot
指定時間にVCから切断するBotです。全員用とユーザー個別の切断時間を設定できます。

### コマンド
- `!sleep 23:30`: コマンド実行者がいるVCの全員用の切断時間を設定します。
- `!sleep 01:00 @ユーザー名`: 同じVCにいる指定ユーザー1人の切断時間を設定します（Botは対象外）。
- `!status`: 全員用・個別の切断時間と対象VCを表示します。

個別設定は、設定順や指定時刻の前後に関係なく全員用より優先されます。
全員用の時刻になっても個別設定のあるユーザーは切断しません。
個別の時刻が先に到来した場合も、設定済みの全員用タイマーが終わるまでは除外を保持します。
全員用を更新しても個別設定は変更されません。同じユーザーの再設定はそのユーザーの設定だけを更新します。

タイマーはサーバーごとに全員用1件・ユーザーごとに個別1件です。
切断対象は設定時のVCにいるユーザーです。別のVCへ移動したユーザーは切断しません。
時刻はBot実行環境のタイムゾーンの `HH:MM` 形式で、過ぎた時刻は翌日として扱います。
タイマーは一度限りで、Botの再起動時には消えます。

### 必要な権限
- メッセージを送る
- メッセージ履歴を読む
- メンバーを移動
